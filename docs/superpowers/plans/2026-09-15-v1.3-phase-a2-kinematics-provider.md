## 1. Goal & Architectural Overview

Phase A2 establishes the **KinematicsProvider Boundary** for VisionRobotTwin. It introduces the abstract `KinematicsProvider` interface, implements `PyBulletKinematicsProvider` for PyBullet forward kinematics, spatial Jacobians, and raw inverse kinematics, migrates `robotics/kinematics.py`, and refactors `GenericIKSolver`, `ResolvedRateController`, `GenericRobotController`, and `PyBulletSimulator` to delegate robot kinematic modeling to `KinematicsProvider`.

```
[ResolvedRateController] ──────────┐
                                   ▼
[GenericIKSolver] ───────► [<<abstract>> KinematicsProvider]
                                   ▲
[GenericRobotController] ──────────┤
  (get_end_effector_pose)          ▼
                        [PyBulletKinematicsProvider]
                        (State-Preserving FK, J_full, solve_ik_raw)
```

- **Spec Document**: [docs/superpowers/specs/2026-09-15-v1.3-phase-a2-kinematics-provider-design.md](../specs/2026-09-15-v1.3-phase-a2-kinematics-provider-design.md)
- **Tech Stack**: Python 3.10 / 3.11 / 3.12, NumPy 2.x, PyBullet 3.2.7, pytest.
- **Baseline Requirement**: All 157 Phase A1 tests remain 100% passing across Windows Python 3.11 and 3.12.

## 2. Global Constraints & Transitional Rules

1. **Test Baseline**: All 157 pre-existing automated tests must remain passing without regressions.
2. **Zero New External Dependencies**: No Pinocchio, KDL, MoveIt 2, or ROS 2 packages in Phase A2.
3. **Reference Artifact Immutability**: All files under `docs/experiments/v1.2_reference/` must remain byte-for-byte unchanged (`git diff main...HEAD -- docs/experiments/v1.2_reference/` returns zero output).
4. **State Preservation (Ruling F)**: Forward kinematics queries on candidate configurations $\mathbf{q}$ must strictly preserve PyBullet joint states ($\mathbf{q}$, $\dot{\mathbf{q}}$) and never advance simulation time (`p.stepSimulation()` is never called).
5. **Numerical Parity (Rulings D, E)**: Post-A2 outputs for FK, Jacobians, and IK solutions must match pre-A2 PyBullet values within tight tolerances ($\le 10^{-6}$), with sign-invariant quaternion parity.
6. **Constructor Compatibility (Ruling C)**: Maintain existing positional parameter orders; add `kinematics_provider` as a trailing optional parameter.
7. **Single Shared Provider (Ruling G)**: In native simulation runtime, one `PyBulletKinematicsProvider` instance is shared across all controller, solver, and manipulability components.
8. **No Empty Milestone Commit (Ruling I)**: The final implementation commit concludes Phase A2 without empty commits.

### Task 3: Implement `PyBulletKinematicsProvider` Forward Kinematics (Ruling F)

**Files to modify**:
- `robotics/kinematics_provider.py`
- `tests/test_kinematics_provider.py`

**Implementation Details**:
- Class `PyBulletKinematicsProvider(KinematicsProvider)`:
  - Constructor: `__init__(self, physics_client_id: int, robot_body_id: int, arm_joint_indices: Sequence[int], end_effector_link_index: int)`
  - `compute_fk(joint_positions: Sequence[float]) -> Tuple[np.ndarray, np.ndarray]`:
    - Validates finite values and vector length == `len(self.arm_joint_indices)` (`ValueError`).
    - Uses `threading.RLock()` to serialize model queries.
    - Saves active joint positions and velocities via `p.getJointStates`.
    - Resets candidate joint angles via `p.resetJointState(..., targetVelocity=0.0)`.
    - Queries `p.getLinkState(..., computeForwardKinematics=True)`.
    - Unconditionally restores original joint states (`q`, `dq`) in `finally:`.
    - Never calls `p.stepSimulation()`.
    - Returns `(pos, orn)` as `(np.ndarray shape (3,), np.ndarray shape (4,))`.

### Task 4: Implement `PyBulletKinematicsProvider` Spatial Jacobian

**Files to modify**:
- `robotics/kinematics_provider.py`
- `tests/test_kinematics_provider.py`

**Implementation Details**:
- `PyBulletKinematicsProvider.compute_jacobian(joint_positions: Sequence[float]) -> Tuple[np.ndarray, np.ndarray, np.ndarray]`:
  - Validates finite values and length matches `len(self.arm_joint_indices)`.
  - Discovers all movable joints (revolute + prismatic) for PyBullet Jacobian compatibility.
  - Pads candidate joint angles with zeros to length $|M|$.
  - Invokes `p.calculateJacobian(bodyUniqueId=self.robot_id, linkIndex=self.ee_link_index, localPosition=[0.0, 0.0, 0.0], objPositions=q_full, objVelocities=zeros, objAccelerations=zeros, physicsClientId=self.client_id)`.
  - Slices the first $n$ columns: $\mathbf{J}_{\text{lin}} = \mathbf{J}_{\text{trans}}[:, :n]$, $\mathbf{J}_{\text{ang}} = \mathbf{J}_{\text{rot}}[:, :n]$, $\mathbf{J}_{\text{full}} = \begin{bmatrix}\mathbf{J}_{\text{lin}} \\ \mathbf{J}_{\text{ang}}\end{bmatrix} \in \mathbb{R}^{6 \times n}$.
  - Returns `(J_lin, J_ang, J_full)`.
