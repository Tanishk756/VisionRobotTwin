## 1. Plan Overview & Architectural Directives

Phase B3 implements the **defensive safety supervision, preflight validation, fault latching, and watchdog layer** (`GuardedRobotBackend` and `CommandSafetySupervisor`).

### Core Rules:
1. **Strict TDD:** Every task writes the failing test first, runs it to verify failure, implements minimal code, verifies test pass, runs regression suite, inspects diff, and commits.
2. **Defensive Rejection:** Safety envelope violations reject commands and latch faults; never silently clamp.
3. **No Physical Hardware Commands:** Zero physical drivers, zero robot IP connections, zero E-stop claims.
4. **Permanent B1 & B2 Invariance:** `ROS2JointStateBackend` remains read-only; `ROS2SimulationBackend` semantics unchanged.
5. **No Mutation of ROS Controllers:** Only read-only `controller_manager` introspection services permitted.
