## 1. Plan Overview & Architectural Directives

Phase B2 implements the **simulation-only command backend** (`ROS2SimulationBackend`) for `ros2_control` forward position and velocity controllers.

### Strict Execution Rules:
- **TDD Requirement:** For every task, write the failing test first, run the test and observe expected failure, write minimum code, verify test passes, run regression suite, inspect diff, and commit.
- **Safety Policy:** Simulation only. Physical robot hardware commands are strictly prohibited.
- **Read-Only Invariance:** `ROS2JointStateBackend` remains permanently read-only and unmodified.
- **Separate Contexts:** `ROS2SimulationBackend` composes `ROS2JointStateBackend` and manages an isolated command context/node.
- **No Command CLI in main.py:** Do not add command flags to `main.py`.
