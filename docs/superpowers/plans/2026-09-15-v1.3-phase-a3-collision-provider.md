## 1. Plan Overview & Principles
Phase A3 decouples collision checking and planning from direct PyBullet simulation handles by introducing the abstract `CollisionProvider` interface.

### Strict Invariants & Binding Rulings
1. **Module Hierarchy & Circular Imports (Ruling A)**: `robotics/collision_provider.py` owns `CollisionResult`, `CollisionProvider`, and `PyBulletCollisionProvider`. `robotics/collision.py` re-exports them and defines `CollisionChecker` subclass.
2. **Planner Parameter Names (Ruling B)**: Preserve `collision_checker` parameter name and position in `planning.py`. Change its type to `CollisionProvider`.
3. **Panda Movable Joints & Gripper Handling (Ruling C)**: Legacy `CollisionChecker` without explicit `arm_joint_indices` dynamically discovers non-fixed joints and takes the first `len(q)` indices (never storing full 9 movable joints). Canonical runtime always passes explicit 7-DoF arm indices.
4. **MotionManager Constructor Compatibility (Ruling D)**: Preserve `collision_checker` as 3rd positional argument. Support optional trailing `collision_provider`.
5. **Shared Model Mutation Lock (Ruling E)**: Inject shared `threading.RLock()` across `PyBulletKinematicsProvider` and `PyBulletCollisionProvider`.
6. **Non-Brittle Golden Tests (Ruling H)**: Assert collision-free status, endpoints, and length bounds rather than floating-point waypoints or wall-clock times.
7. **Deterministic Synchronization Tests (Ruling I)**: Assert lock identity and property checks; no flaky timing/sleep tests.

## 3. Backward Compatibility Matrix
| Component / Function | Pre-A3 Usage | Post-A3 Compatibility |
| :--- | :--- | :--- |
| `CollisionChecker(...)` | Instantiated PyBullet collision engine | Subclass of `PyBulletCollisionProvider` (100% compatible) |
| `check_collision(q, arm_joint_indices)` | PyBullet collision query with optional joint indices | Supported on `CollisionChecker` & `PyBulletCollisionProvider` |
| `RRTConnectPlanner(...)` | Accepted `collision_checker` parameter | Accepts `CollisionProvider` under same parameter name |
| `is_joint_path_collision_free(...)` | Checked path with `collision_checker` | Accepts any `CollisionProvider` under same parameter name |
| `MotionManager(...)` | Accepted `collision_checker` | Accepts `collision_checker` or `collision_provider` |
| `PyBulletSimulator.collision_checker` | Attribute on simulator | Aliased to `self.collision_provider` |
