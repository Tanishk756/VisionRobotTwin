## 1. Plan Overview & Principles
Phase A3 decouples collision checking and planning from direct PyBullet simulation handles by introducing the abstract `CollisionProvider` interface.

### Strict Invariants
1. **Zero Algorithm Drift**: RRT-Connect, path shortcutting, clearance calculations, and contact whitelisting logic remain identical.
2. **Shared Model Mutation Lock**: A single `threading.RLock()` per robot body synchronizes state overrides between `PyBulletKinematicsProvider` and `PyBulletCollisionProvider`.
3. **State Preservation**: Candidate configuration checks must save and restore `(q, dq)` with 0 calls to `p.stepSimulation()`.
4. **Backward Compatibility**: `CollisionChecker` remains available as a subclass/wrapper of `PyBulletCollisionProvider`.
5. **Reference Artifact Immutability**: `docs/experiments/v1.2_reference/` is never modified.

## 3. Backward Compatibility Matrix
| Component / Function | Pre-A3 Usage | Post-A3 Compatibility |
| :--- | :--- | :--- |
| `CollisionChecker(...)` | Instantiated PyBullet collision engine | Subclass of `PyBulletCollisionProvider` (100% compatible) |
| `check_collision(q, arm_joint_indices)` | PyBullet collision query with optional joint indices | Supported on `CollisionChecker` & `PyBulletCollisionProvider` |
| `RRTConnectPlanner(...)` | Accepted `CollisionChecker` and `arm_joint_indices` | Accepts `CollisionProvider` (optional `arm_joint_indices` ignored) |
| `is_joint_path_collision_free(...)` | Checked path with `CollisionChecker` | Accepts any `CollisionProvider` |
| `MotionManager(...)` | Accepted `collision_checker` | Accepts `collision_checker` or `collision_provider` |
| `PyBulletSimulator.collision_checker` | Attribute on simulator | Aliased to `self.collision_provider` |
