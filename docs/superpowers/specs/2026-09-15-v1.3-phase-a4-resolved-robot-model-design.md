## 1. Executive Summary & Problem Statement
Following the completion of **Phase A1** (`RobotBackend`), **Phase A2** (`KinematicsProvider`), and **Phase A3** (`CollisionProvider`), all major robotics execution, kinematics, and collision query services have been decoupled from direct PyBullet engine bindings.

However, **`GenericRobotController`** remains tightly coupled to PyBullet at initialization time:
1. It imports `pybullet as p` and directly invokes C-API queries (`p.getNumJoints`, `p.getJointInfo`, `p.JOINT_REVOLUTE`, `p.JOINT_PRISMATIC`, `p.resetJointState`).
2. Its constructor requires mandatory `physics_client_id` and `robot_id` integers.
3. It performs runtime URDF inspection via `_inspect_urdf()` by querying the active PyBullet physics server directly.
4. It executes an implicit simulation teleport (`reset_to_home()` using `p.resetJointState`) as a constructor side effect.

Consequently, injecting a `MockRobotBackend` or future `ROS2RobotBackend` into `GenericRobotController` cannot succeed without spinning up a live PyBullet simulation client and loading a URDF into it.

**Phase A4** resolves this final foundation barrier by establishing a clear separation between:
- **`RobotModelSpec`**: Declarative static configuration, hardware capability flags, and path patterns.
- **`ResolvedRobotModel`**: Strongly-typed, immutable runtime model metadata (ordered arm joints, gripper joints, limits, velocities, forces, link names, end-effector identification, home poses).
- **`PyBulletRobotModelResolver`**: PyBullet-specific URDF inspection and adapter limit-fixing utility that produces a `ResolvedRobotModel`.
- **`GenericRobotController`**: Pure control policy, rate limiting, velocity clamping, and metadata consumer operating via `ResolvedRobotModel`, `RobotBackend`, and `KinematicsProvider` with **0 PyBullet imports and 0 direct PyBullet calls** in the generic path.

## 2. Binding A4 Architectural Rulings

### Ruling A — Generic Module Must Not Import PyBullet Transitively
`robotics/robot_controller.py` must NOT have unconditional top-level imports of:
- `pybullet`
- `PyBulletRobotBackend`
- `PyBulletKinematicsProvider`
- `PyBulletRobotModelResolver`
The generic controller and data models must be fully importable in an environment without PyBullet. Legacy PyBullet construction paths use lazy imports inside the legacy constructor branch.

### Ruling B — Preserve Joint Type Compatibility with JointMotionType
To preserve `JointInfo.joint_type` compatibility without importing PyBullet constants, define a generic enum `JointMotionType`:
- `REVOLUTE`, `PRISMATIC`, `FIXED`, `OTHER`.
`ResolvedJointMetadata` contains both `motion_type: JointMotionType` and `native_joint_type: Optional[int] = None`. The resolver maps PyBullet integer constants to `JointMotionType` while capturing `native_joint_type` for opaque diagnostic/legacy compatibility.

### Ruling C — Unique Model Index
Add `model_index: int` (0-based position in `all_joints`) to `ResolvedJointMetadata`, alongside `canonical_index: int` (role-local 0-based index) and `native_index: Optional[int] = None` (engine handle).

### Ruling D — Substring Role Classification
Joint role classification uses case-insensitive substring matching against `spec.arm_joint_name_patterns` and `spec.gripper_joint_name_patterns` on movable joints rather than generic regex or type assumptions:
- Gripper pattern match on movable joint -> `GRIPPER`
- Arm pattern match on movable joint -> `ARM`
- Fixed joint -> `OTHER`
- Unmatched movable joint -> `OTHER`

### Ruling E — Safe Engine Handle Extraction
`ResolvedRobotModel` provides explicit, validated accessors `require_arm_native_indices() -> Tuple[int, ...]` and `require_gripper_native_indices() -> Tuple[int, ...]`, which raise `ValueError` if any required native index is `None` (preventing silent vector truncation).

### Ruling F — No Motion Side Effect on Controller Construction
Controller construction never commands motion, velocity, or simulation teleport. `PyBulletSimulator` is explicitly responsible for initial simulation teleport.

## 3. Data Model Architecture

### 3.1 `JointRole` & `JointMotionType`
```python
from enum import Enum, auto

class JointRole(Enum):
    """Categorized role of a robot joint in manipulator control."""
    ARM = auto()
    GRIPPER = auto()
    OTHER = auto()

class JointMotionType(Enum):
    """Generic kinematic motion type of a joint."""
    REVOLUTE = auto()
    PRISMATIC = auto()
    FIXED = auto()
    OTHER = auto()
```

### 3.2 `ResolvedJointMetadata`
```python
@dataclass(frozen=True)
class ResolvedJointMetadata:
    """Immutable metadata for an individual robot joint.

    Attributes:
        model_index: Stable 0-based index in the overall model's joint list.
        canonical_index: 0-based index within its specific role (e.g. 0..6 for 7-DoF arm).
        name: Joint identifier name (e.g. 'panda_joint1').
        role: Functional role (ARM, GRIPPER, or OTHER).
        motion_type: Kinematic motion type (REVOLUTE, PRISMATIC, FIXED, OTHER).
        lower_limit: Minimum joint position limit (rad or m).
        upper_limit: Maximum joint position limit (rad or m).
        max_force: Maximum allowable effort/torque (N or Nm).
        max_velocity: Maximum allowable angular or linear velocity (rad/s or m/s).
        link_name: Name of the child link attached to this joint.
        native_index: Optional engine-native index (e.g. PyBullet joint integer ID).
        native_joint_type: Optional engine-native joint type identifier.
    """
    model_index: int
    canonical_index: int
    name: str
    role: JointRole
    motion_type: JointMotionType
    lower_limit: float
    upper_limit: float
    max_force: float
    max_velocity: float
    link_name: str
    native_index: Optional[int] = None
    native_joint_type: Optional[int] = None
```

### 3.3 `ResolvedRobotModel`
```python
@dataclass(frozen=True)
class ResolvedRobotModel:
    """Immutable, fully resolved kinematic and dynamic metadata for a robotic manipulator."""
    robot_id: str
    display_name: str
    all_joints: Tuple[ResolvedJointMetadata, ...]
    arm_joints: Tuple[ResolvedJointMetadata, ...]
    gripper_joints: Tuple[ResolvedJointMetadata, ...]
    ee_link_name: str
    ee_link_native_index: Optional[int] = None
    home_joint_positions: Tuple[float, ...] = ()
    capabilities: RobotCapabilities = field(
        default_factory=lambda: RobotCapabilities(has_gripper=False, supports_pick_place=False)
    )

    @property
    def dof(self) -> int:
        return len(self.arm_joints)

    @property
    def arm_joint_names(self) -> Tuple[str, ...]:
        return tuple(j.name for j in self.arm_joints)

    @property
    def arm_lower_limits(self) -> Tuple[float, ...]:
        return tuple(j.lower_limit for j in self.arm_joints)

    @property
    def arm_upper_limits(self) -> Tuple[float, ...]:
        return tuple(j.upper_limit for j in self.arm_joints)

    @property
    def arm_joint_ranges(self) -> Tuple[float, ...]:
        return tuple(j.upper_limit - j.lower_limit for j in self.arm_joints)

    @property
    def arm_max_velocities(self) -> Tuple[float, ...]:
        return tuple(j.max_velocity for j in self.arm_joints)

    @property
    def arm_max_forces(self) -> Tuple[float, ...]:
        return tuple(j.max_force for j in self.arm_joints)

    def require_arm_native_indices(self) -> Tuple[int, ...]:
        indices = []
        for j in self.arm_joints:
            if j.native_index is None:
                raise ValueError(f"Arm joint '{j.name}' lacks a native_index")
            indices.append(j.native_index)
        return tuple(indices)

    def require_gripper_native_indices(self) -> Tuple[int, ...]:
        indices = []
        for j in self.gripper_joints:
            if j.native_index is None:
                raise ValueError(f"Gripper joint '{j.name}' lacks a native_index")
            indices.append(j.native_index)
        return tuple(indices)
```

## 4. PyBullet Robot Model Resolver

The resolver lives in `robotics/pybullet_model.py`:
- Converts PyBullet C-API joint inspections (`p.getNumJoints`, `p.getJointInfo`) into `ResolvedRobotModel`.
- Applies `adapter.fix_joint_limits()`.
- Maps joint types to `JointMotionType`.
- Applies substring role classification against `spec.arm_joint_name_patterns` and `spec.gripper_joint_name_patterns`.
- Identifies EE link index and name.
- Provides simulation-only helper `teleport_robot_to_home(physics_client_id, robot_body_id, resolved_model)` (sets arm home and Panda finger 0.04).

## 5. GenericRobotController Refactoring

### 5.1 Signature & Decoupling
```python
class GenericRobotController:
    def __init__(
        self,
        physics_client_id: Optional[int] = None,
        robot_id: Optional[int] = None,
        spec: Optional[RobotModelSpec] = None,
        adapter: Optional[RobotAdapter] = None,
        config: Optional[RobotConfig] = None,
        backend: Optional[RobotBackend] = None,
        kinematics_provider: Optional[KinematicsProvider] = None,
        model_query_lock: Optional[threading.RLock] = None,
        resolved_model: Optional[ResolvedRobotModel] = None,
    ):
```
- **Zero top-level PyBullet imports in `robotics/robot_controller.py`**.
- Generic path reads limits, ranges, velocities, and names strictly from `self.model`.
- Validates backend joint names upon acquisition without blocking async backend designs.
- Backward-compatible properties (`joints`, `arm_joint_indices`, `finger_joint_indices`, `ee_link_index`) are preserved via `self.model`.
