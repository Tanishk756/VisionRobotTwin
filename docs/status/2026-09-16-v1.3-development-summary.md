## 1. Executive Summary & Architectural Overview

**VisionRobotTwin v1.3** transforms the platform from a PyBullet-coupled multi-manipulator simulation tool into an extensible, backend-agnostic, and safety-supervised robotics execution framework.

```mermaid
flowchart TD
    subgraph HighLevel ["🎯 High-Level Control & Planning"]
        Perception[OpenCV ArUco Perception / SLERP Filter] --> WSMapper[Workspace Bounds & Slew Limiter]
        WSMapper --> FSM[Autonomous State Machine / Teleop]
        FSM --> Controller[GenericRobotController / ResolvedRateController / MotionManager]
    end

    subgraph AbstractionLayer ["🧩 Core Architectural Provider Abstractions (Phases A1-A4)"]
        Controller --> RRM[ResolvedRobotModel: Canonical Metadata & Limits]
        Controller --> KP[KinematicsProvider: FK, Spatial Jacobian, SVD, IK]
        Controller --> CP[CollisionProvider: Self & Environment Collision, RRT-Connect]
    end

    subgraph SafetyLayer ["🛡️ Hardware-Readiness Safety Layer (Phase B3)"]
        Controller --> Guard[GuardedRobotBackend: Preflight, Limits, Watchdog, Fault Latching]
    end

    subgraph BackendExecution ["🦾 Execution Backends"]
        Guard -->|Sim 1| PB[PyBulletRobotBackend: 240 Hz Physics Twin]
        Guard -->|Sim 2| Mock[MockRobotBackend: Isolated Deterministic Testing]
        Guard -->|Sim 3| ROS2Sim[ROS2SimulationBackend: ros2_control Forward Controllers]
        Guard -.->|Future B4.2| RealPhys[PhysicalRobotBackend: BLOCKED]
    end

    subgraph PhysicalCommissioning ["🔍 Read-Only Physical Commissioning (Phase B4.1)"]
        PhysProv[PhysicalTelemetryProvider: Mock / Future Hardware Adapter] --> PhysState[PhysicalRobotStateBackend: Strictly Read-Only]
        PhysState --> Readiness[PhysicalReadinessEvaluator: Identity & Safety Checks]
        PhysState --> Provenance[LimitProvenanceEngine: Interval Intersection]
        PhysState --> Soak[PhysicalObservationSession: Motionless Health & Gap Tracking]
        PhysState --> Trace[CommissioningSessionRecord: Immutable SHA Traceability]
    end
```
